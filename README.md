## About my project

**ClaimCheck** takes a news item, social media post or WhatsApp forward, splits it into individual factual claims, retrieves evidence from Wikipedia and local notes, and uses a **local Ollama LLM** to label each claim *supported*, *contradicted* or *not enough evidence*. Every verdict must quote its source, and the code checks that the quote really exists, so the model cannot invent evidence.
